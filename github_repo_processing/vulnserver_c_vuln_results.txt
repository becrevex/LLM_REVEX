#### **Vulnerability Title:** Command Injection
**Severity Estimate:** High (Exploitable)

**Why it is a vulnerability:** The `Function3` and `Function4` functions do not properly sanitize or validate the input they receive before using it in a command execution. This can lead to command injection attacks.

**The relevant code pattern or function involved:**
```c
void Function3(char *Input) {
    char Buffer2S[2000];	
    strcpy(Buffer2S, Input);
}

void Function4(char *Input) {
    char Buffer2S[1000];
    strcpy(Buffer2S, Input);
}
```

**How it may be exploited:**
An attacker could exploit this vulnerability by sending a specially crafted input that includes malicious commands. For example, an attacker might send `Function3("echo; rm -rf /")` to delete the entire filesystem.

**Recommended remediation:**
Use parameterized queries or prepared statements to ensure input is sanitized before execution. Replace `strcpy` with safe functions like `strncpy` with a size limit, or use formatted string operations that prevent injection.
